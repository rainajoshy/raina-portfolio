# Raina Portfolio

A React portfolio customized with the name Raina and the profile photo supplied in the chat.

## Run locally
1. Extract this ZIP.
2. Open the extracted `raina-portfolio` folder in VS Code.
3. Open Terminal in VS Code.
4. Run `npm install` (first time only).
5. Run `npm start`.
6. Open http://localhost:3000.

The contact form is a front-end demo and is not connected to an email service. Add your own contact details and confirmed education information before publishing.
